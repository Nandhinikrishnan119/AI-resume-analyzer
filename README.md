# ResumeAI

ResumeAI is a modern React + Vite landing page and resume-analysis experience for job seekers. It includes a polished home experience, about page, upload flow, login view, and dashboard-style results screen.

## Features

- Clean, minimal UI with dark premium styling
- Responsive navigation and mobile-friendly layout
- Resume upload experience with progress states
- ATS-style dashboard with suggestions and score breakdown
- React Router-based multi-page navigation

## Tech Stack

- React 19
- Vite 8
- React Router DOM
- Lucide React
- CSS custom properties for the visual system

## Getting Started

1. Install dependencies
   ```bash
   npm install
   ```
2. Start the development server
   ```bash
   npm run dev
   ```
3. Open the local URL shown by Vite in your browser.

## Build

```bash
npm run build
```

## Project Structure

- src/pages — main route pages
- src/components — shared UI and section components
- src/index.css — global styles and design tokens

## Deployment

This project is ready to be deployed on Vercel, Netlify, or any static host.
